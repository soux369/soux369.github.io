warii が提供する機能とデザイン

直感的に使えるシンプルな機能で、お支払いを円滑に進めます。

01 / DASHBOARD

グループ一覧と直感的な作成

作成した割り勘グループが一覧で表示され、進捗や総支出が一目で確認できます。合宿や旅行など、イベントごとに切り替えて管理が可能です。

  • ✔ アカウント不要で即座に開始可能
  • ✔ グループごとに為替レートを設定可能
  • ✔ 送金が完了したグループはワンタップで整理
02 / CALCULATION

複雑な立替計算も一瞬で解決

誰がいくら支払ったかを記録するだけで、全員の最終的な精算金額（誰から誰へ、いくら送金すればいいか）を最小限の送金回数で自動算出します。

  • ✔ 均等割りから個別の比率（パーセンテージ）割りまで対応
  • ✔ 割り勘から特定メンバーを除外する設定も可能
  • ✔ 変更内容や出費はリアルタイムにクラウド同期
03 / PAYMENT SHARING

送金先を1タップでかんたん共有

支払先となるメンバーのPayPayリンクをタップして公式アプリを呼び出したり、銀行口座情報を1タップで安全にコピーできます。

  • ✔ 面倒な口座番号の手入力・転記のミスを防ぎます
  • ✔ PayPay・振込メモの優先順位を登録可能
  • ✔ アプリを持たないメンバーへもWebリンクで共有可能
🔒 高度な暗号化保護

E2EE（エンドツーエンド）暗号化テクノロジー

あなたが登録した口座メモやPayPayリンクなどの個人データは、あなたの端末から送信される直前に、強力なAES-256暗号化処理が施されます。


暗号化されたデータは、共有リンクに含まれる「秘密キー」でのみ解読できます。この秘密キーはサーバーには一切送信・保存されないため、開発者を含むいかなる第三者も中身を知ることは不可能です。

よくあるご質問

安心してご利用いただくための回答集です。

利用に会員登録は必要ですか？

いいえ、インストール後すぐにログイン不要でお使いいただけます。グループを作成し、友達を招待するだけで割り勘を開始できます。

データはいつまで保存されますか？

サーバーデータの保存期間は、最終更新（追加・編集・同期）から30日間です。30日を過ぎるとサーバーから自動で完全削除されます。

登録したお支払メモは本当に安全ですか？

はい、すべての支払情報はエンドツーエンド（E2EE）で強力に暗号化されてからサーバーに送信されます。サーバー管理者もデータを見ることはできない設計ですのでご安心ください。
